Complete Windows x64 portable desktop app, including all current features and fixes.

Download Riser-Studio-Windows.zip, extract the entire archive into a new folder, then run Riser-Studio.exe. Keep its supporting files together. Use File → Open for existing .riser projects.

Includes the desktop startup fix, internal MSB breakers and busbar junction dots, red fire circuits, visible checkboxes and the Show cable sizes option. This build is unsigned. Automated code/package checks run; actual Windows launch remains untested.
